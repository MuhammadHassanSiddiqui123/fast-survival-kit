## 📖 About

University is easier when you're not starting from scratch. This repo collects study material for FAST BSCS students in one place, so you can find what you need quickly instead of digging through old group chats.

Built by students, for students.

## 📂 Structure

```
BSCS/
├── Sem1/
├── Sem2/
├── Sem3/
├── Sem4/
├── Sem5/
├── Sem6/
├── Sem7/
└── Sem8/
```

Inside each semester, every course gets its own folder:

```
Sem5/
└── Course-Name/
    ├── Lectures/
    ├── Assignments/
    ├── Quizzes/
    └── Past-Papers/
```

## 🔍 How to Use

1. Open the folder for your semester.
2. Pick your course.
3. Download what you need, or click a file to preview it.

Tip: press `T` on any page in the repo to search for a file by name.

## 🤝 Contributing

Got material that could help others? Add it!

1. Place files in the correct `Sem/Course/Category` folder.
2. Use clear, consistent names, for example:
   - `Lecture01-Introduction.pdf`
   - `Assignment2-Solution.pdf`
   - `Midterm-Fall2024.pdf`
3. Keep files reasonably sized. For large files (videos, big PDFs), upload them to Google Drive and add a link in the course folder's README.
4. If you're not a collaborator, open a **Pull Request** or an **Issue** with your material.

## ⚠️ Guidelines

- Do not upload copyrighted textbooks or paid material.
- Do not upload anything the university prohibits sharing.
- Keep personal information (roll numbers, phone numbers) out of uploaded files.
- Material may contain mistakes. Always verify against your instructor's guidance.
